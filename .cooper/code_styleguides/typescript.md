# TypeScript style guide

Use strict TypeScript, named exports, and descriptive types for ritual and interaction stages. Prefer const and avoid any; narrow unknown values when handling external data.

Follow the surrounding single-quote, semicolon-free style. Keep frame-by-frame transforms in Three.js refs and discrete ceremony progress in the store. Preserve native input focus and clean up event listeners.

Separate reusable geometry from interaction policy. Keep source spout positions, target openings, and object home poses explicit and testable.

Follow Red/Green/Refactor for executable changes. Write behavior-focused Vitest tests and real-input Playwright scenarios where appropriate. Target coverage greater than 80%, reporting actual measurements and missing instrumentation accurately.
