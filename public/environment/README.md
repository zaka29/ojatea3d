# Room lighting asset

`lebombo_1k.hdr` is the unmodified environment used by Drei's `apartment` preset.
It is bundled here to keep the scene and its regression tests independent of the remote asset host.

Source: https://raw.githack.com/pmndrs/drei-assets/456060a26bbeb8fdf79326f224b6d99b8bcce736/hdri/lebombo_1k.hdr
